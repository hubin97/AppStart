# AppStart 大特性任务 Prompt 模板

复制到 Cursor 对话中使用，按实际填写。

```markdown
## 目标
在 AppStart 中：……（一句话）

## 非目标
- …

## 范围
- 允许改：AppStart/AppStart/某模块/**
- 禁止改：Example/Pods/**、（默认）AppTemplate/**

## 执行方式
1. 先只读，给计划与影响面
2. 确认后再改代码
3. 按 AppStart/AGENTS.md 收尾

## Demo 决策（必填）
- 是否需要 AppTemplate Demo：是 / 否 / 先改库再决定
- 若是：Demo 页面/入口：
- 若否：原因：

## 验收
- [ ] …
- [ ] 大特性已处理 Demo 询问与结果
```
